# ITS2 reference database

The ITS2 series will be released independently from RTBioScan and from the COI
series. No ITS2 FASTA, BLAST index, release provenance, or canonical semantic
version is published from this repository yet.

The source collection was compiled following the semi-automated curation
approach for reliable vascular-plant ITS2 reference data described by Quaresma
et al. (2024), integrating public barcode records and applying taxonomic and
sequence-quality curation. The collection was supplemented with barcode
sequences generated by the project. To reduce redundancy and sensitivity to
stochastic representative selection, the combined sequences were clustered
with CD-HIT at 98% nucleotide identity, and the representative of each cluster
was assigned to the last common ancestor of the records in that cluster.

Before the first release, the exact source identities, quality filters,
clustering parameters, taxonomic reassignment rules, record and base counts,
artifact hashes, and independent verification results must be frozen in
versioned provenance. The release must use its own ITS2 tag series and Zenodo
record; COI release identifiers and checksums do not apply to it.

Quaresma, A., et al. (2024). Semi-Automated Sequence Curation for Reliable
Reference Datasets in ITS2 Vascular Plant DNA (Meta-)Barcoding.
*Scientific Data*, 11, 129.
<https://doi.org/10.1038/s41597-024-02962-5>
